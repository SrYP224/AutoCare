# Idea 1

## AutoCare - Control de Mantenimiento Vehicular

AutoCare es una aplicación móvil orientada a propietarios de vehículos que necesitan llevar un control sencillo del mantenimiento de su automóvil.

La aplicación permitirá registrar la información básica del vehículo y almacenar un historial de los mantenimientos realizados, incluyendo el tipo de servicio, fecha, kilometraje, costo y descripción.

Además, permitirá consultar el total gastado en mantenimiento y realizar un seguimiento del próximo servicio recomendado según el kilometraje.

### Problema

Los propietarios de vehículos pueden olvidar cuándo realizaron un mantenimiento, cuánto gastaron o en qué kilometraje se realizó determinado servicio.

Esto puede dificultar el seguimiento adecuado del mantenimiento preventivo del vehículo.

### Solución propuesta

Desarrollar una aplicación móvil que permita centralizar esta información y presentarla de forma sencilla y organizada.

### Funcionalidades principales

- Registro del vehículo.
- Consulta y actualización del kilometraje.
- Registro de mantenimientos.
- Historial de mantenimientos.
- Edición y eliminación de registros.
- Registro de costos.
- Cálculo del gasto total.
- Seguimiento del próximo mantenimiento.

### Tecnologías propuestas

- Kotlin.
- Jetpack Compose.
- Room.
- SQLite.
- Material 3.
- Android Studio.

### Aplicaciones similares

- [Simply Auto: Mantenimiento](https://play.google.com/store/apps/details?id=mrigapps.andriod.fuelcons)

# Idea 2

## EcoPuntos - Registro de Reciclaje

EcoPuntos sería una aplicación móvil para registrar y consultar las actividades de reciclaje realizadas por un usuario.

La aplicación permitiría registrar diferentes tipos de materiales reciclables, como plástico, cartón, vidrio y metal, indicando la cantidad recolectada y la fecha.

El sistema podría asignar puntos de acuerdo con la cantidad y tipo de material reciclado.

### Funcionalidades principales

- Registrar material reciclado.
- Seleccionar tipo de material.
- Registrar cantidad.
- Consultar historial.
- Calcular puntos acumulados.
- Consultar estadísticas básicas.
- Editar registros.
- Eliminar registros.

### Tecnologías propuestas

- Kotlin.
- Jetpack Compose.
- Room.
- SQLite.
- Material 3.

### Aplicaciones similares

- [Ecosia](https://play.google.com/)
- [Recycle Coach](https://play.google.com/)

# Idea seleccionada

La idea seleccionada para el desarrollo del proyecto es:

## AutoCare - Control de Mantenimiento Vehicular

Se seleccionó esta propuesta debido a que presenta un alcance adecuado para el tiempo disponible y permite implementar diferentes conceptos de desarrollo móvil, incluyendo interfaces con Jetpack Compose, persistencia local, operaciones CRUD, navegación, validación de datos y manejo de estados.

El proyecto también permite dividir el trabajo entre los tres integrantes del grupo sin requerir una infraestructura compleja.
