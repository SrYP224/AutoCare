# Idea 1

## AutoCare - Control de Mantenimiento Vehicular

Aplicación móvil para que los propietarios de vehículos lleven un control sencillo del mantenimiento de su automóvil. La descripción completa y el problema que resuelve están en el [README](../README.md); las funciones, en [funcionalidades.md](funcionalidades.md).

### Aplicaciones similares

- [Drivvo - Gastos de coche](https://play.google.com/store/apps/details?id=br.com.ctncardoso.ctncar): permite gestionar gastos, mantenimiento, cambios de aceite y otros servicios del vehículo, además de programar recordatorios por fecha o kilometraje.
- [Simply Auto: Mantenimiento](https://play.google.com/store/apps/details?id=mrigapps.andriod.fuelcons): permite registrar servicios, gastos y mantenimientos, así como establecer recordatorios por fecha o kilometraje.

# Idea 2

## EcoPuntos - Registro de Reciclaje

EcoPuntos sería una aplicación móvil para registrar y consultar las actividades de reciclaje realizadas por un usuario.

La aplicación permitiría registrar diferentes tipos de materiales reciclables, como plástico, cartón, vidrio y metal, indicando la cantidad recolectada y la fecha.

El sistema podría asignar puntos de acuerdo con la cantidad y tipo de material reciclado.

### Funcionalidades principales

- Registrar material reciclado.
- Seleccionar tipo de material.
- Registrar cantidad.
- Consultar historial.
- Calcular puntos acumulados.
- Consultar estadísticas básicas.
- Editar registros.
- Eliminar registros.

### Tecnologías propuestas

- Kotlin.
- Jetpack Compose.
- Room.
- SQLite.
- Material 3.

### Aplicaciones similares

- [Ecosia](https://play.google.com/)
- [Recycle Coach](https://play.google.com/)

# Idea seleccionada

La idea seleccionada para el desarrollo del proyecto es:

## AutoCare - Control de Mantenimiento Vehicular

Se seleccionó esta propuesta debido a que presenta un alcance adecuado para el tiempo disponible y permite implementar diferentes conceptos de desarrollo móvil, incluyendo interfaces con Jetpack Compose, persistencia local, operaciones CRUD, navegación, validación de datos y manejo de estados.

El proyecto también permite dividir el trabajo entre los tres integrantes del grupo sin requerir una infraestructura compleja.
